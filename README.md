# Student Registration & Contact Intelligence System

**Course:** BCA Semester 1 – Python Programming  
**Project:** Student Registration & Contact Intelligence System

## 1. Project overview

This is a menu-driven, pure-Python application that reads student contact records from a CSV file, validates them, rejects faulty or duplicate records, manages accepted students, and produces a Business Intelligence (BI) report.

The project uses only Python's standard library. No SQL database or third-party package is required.

## 2. Requirements

- Python 3.8 or later
- `contacts.csv` in the project folder
- Terminal / Command Prompt

## 3. Project structure

```text
student_registration/
├── contacts.csv
├── validator.py
├── loader.py
├── analytics.py
├── main.py
├── students_clean.csv       # generated automatically
├── README.md
└── proof/
    ├── test_cases.txt

```

## 4. How to run

1. Extract the project ZIP.
2. Open a terminal in the `student_registration` folder.
3. Run:

   ```bash
   python main.py
   ```

4. Choose a menu option from 1 to 7.
5. Choose option 7 to save the latest data and exit.

On some systems, use `python3 main.py` instead.

## 5. Module descriptions

- **validator.py:** `validate_contact(name, phone, email)` checks the name, phone number, and email address. It returns `(is_valid, reason)`.
- **loader.py:** Reads the input CSV using `csv.DictReader`, validates every row, prevents duplicate phone numbers and email addresses, logs rejected rows, and writes accepted rows to `students_clean.csv`.
- **analytics.py:** Calculates acceptance percentage, rejection reasons, phone-prefix distribution, and email-domain distribution.
- **main.py:** Provides the seven-option interactive student management console.

## 6. Validation rules

- Name cannot be blank or only whitespace.
- Phone must contain exactly 10 digits and start with 6, 7, 8, or 9.
- Email must contain exactly one `@`, no whitespace, a non-empty part before `@`, and a domain containing a period that is not at the beginning or end.
- Duplicate phone numbers and email addresses are rejected.

## 7. Menu options

1. View all students
2. Search by name, phone number, or email
3. Register a student
4. Update an existing student
5. Delete by student ID or phone number
6. Generate analytics report
7. Save and exit

## 8. Important notes

- `students_clean.csv` is generated when the application starts and updated after register, update, delete, and exit operations.
- The original `contacts.csv` is not modified.
- Student IDs are generated by the program.
- The sample data is for academic demonstration only.
